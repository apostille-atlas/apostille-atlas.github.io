# Apostille Atlas: boring-niche directory site

A static directory of U.S. apostille offices (state + federal) with fees, addresses, timing and requirements, each fact cited to an official government page. No framework or dependencies; you only need Python 3.

## Layout
- `data/states.json`: one record per state (facts + `sources`)
- `content/guides/*.html`: guide pages (JSON front matter in the first `<!-- -->` comment)
- `build.py`: generates `dist/` (HTML, JSON-LD, `sitemap.xml`, `robots.txt`, `llms.txt`, `404.html`)
- `config.json`: site name, **site_url** (set this to the real domain before deploying), last-verified date
- `scripts/new_page.py`: scaffolds the next backlog item as a draft
- `backlog.md`: page ideas, ordered by real demand (see its header)
- `research/`: niche rationale, affiliate program list, and `questions.md` (real user questions with sources; FAQs must come from here)
- `data/faq.json`: FAQ hub questions/answers/sources
- `outreach/`: draft partner emails (NOT sent)

## Build & preview
    python3 build.py
    cd dist && python3 -m http.server 8000   # open http://localhost:8000

## Nightly page checklist (~30–45 min)
1. `python3 scripts/new_page.py`: creates a draft for the next backlog item.
2. Open the **official** source (state SOS or equivalent, travel.state.gov, hcch.net). Do not copy facts from competitor sites.
3. Fill in every `TODO`: fee, mail/in-person options, address, payment, what to send, and pitfalls. If the office doesn't publish a processing time, say so instead of guessing.
4. Add each official URL to `sources`. Delete `"draft": true`. (The build skips drafts and pages with no sources.)
5. **Direct-answer summary** (required): set `"summary"`, 2–3 plain sentences answering "where, how much, how long" using only facts from the official sources. No guesses.
6. **FAQs from real questions** (required): set `"faqs"` (guides: front matter; states get 5 generated FAQs automatically). Each question must match one logged in `research/questions.md` with its source link. Add any new real question you find there first. Answers cite the official page, or say the answer is unknown/varies.
7. **Question-style headings**: phrase `<h2>`s as the questions people ask ("How long does a X apostille take?").
8. **Internal links** (required): link the page to its state(s), the relevant guides, `/faq/` and `/directory/`. State pages get guide links and other-state links automatically; add at least 2 in-body links in guides.
9. **Titles**: under 60 characters (the build fails otherwise). States: "<State> Apostille: Where to Go, $<fee> Fee & Steps". Descriptions ≤ 155 characters.
10. **JSON-LD** is generated by `build.py`: Article + BreadcrumbList on every content page, FAQPage when `faqs` exist, HowTo on states, WebSite on home. Don't hand-write it. Set `"last_reviewed"` (YYYY-MM-DD) when you re-check a page; it drives the visible "Last reviewed" date and the sitemap `lastmod`.
11. `python3 build.py` and preview locally. Check: no broken internal links, every `application/ld+json` block parses with `json.loads`, GoatCounter snippet present.
12. `python3 scripts/new_page.py --done`, then commit and push (GitHub Actions deploys), then `python3 scripts/indexnow.py`.
13. Monthly: re-check fees and addresses on existing pages, and update `last_verified` in `config.json`.

## SEO / AI-assistant files (generated by build.py; never edit `dist/` by hand)
- `/llms.txt`: site summary, page index and one-line key facts per state for AI assistants; `/llms-full.txt`: every short answer and FAQ in plain text.
- Every page: title < 60 and description ≤ 155 chars (build asserts both), canonical, robots meta, Open Graph + Twitter large card (`static/og.png`), favicons, inlined CSS (no render-blocking stylesheet), JSON-LD graph with WebSite + Organization (`@id` references), visible "Last reviewed" date and a direct-answer summary.
- State pages link automatically to neighboring covered states (`NEIGHBORS` in build.py) and the most-requested states (`HIGH_DEMAND`); guides and the FAQ hub link to every state page; `/404.html` is a noindex page with hub links.
- `/robots.txt`: allows all crawlers, naming GPTBot, OAI-SearchBot, ChatGPT-User, ClaudeBot, Claude-SearchBot, PerplexityBot, Google-Extended, Googlebot, Bingbot, Applebot, Applebot-Extended, CCBot, Perplexity-User, Amazonbot, DuckAssistBot, Meta-ExternalAgent, MistralAI-User and YouBot, and points to the sitemap.
- `/sitemap.xml`: each URL has `lastmod`.
- `/faq/`: hub answering common questions from `data/faq.json` (each item: question, answer HTML, official sources).
- Analytics: GoatCounter (cookieless), in the shared template in `build.py`.

## Affiliate links
Live: Apostille USA (state pages, birth certificate guide, federal guides) and Fingerprints & Apostilles (FBI and Dept. of State guides), both also on /guides/apostille-services-compared/ (DIY vs paid services; service prices only as published on each service's own page, re-check before editing); see research/affiliate-programs.md.
- State pages and the FBI / Dept. of State guides get a "Don't want to do it yourself?" box right under the short answer, generated by `aff_box()` in `build.py` (guides opt in with the `<!--AFF_BOX_FEDERAL-->` marker). It says DIY with the official office is cheaper (official fee + source), when a service can be worth it, and quotes partner prices only as published on the partner's own site (cited). Re-check those prices monthly; never add speed or price claims a partner doesn't publish.
- Every affiliate link must have `rel="sponsored nofollow noopener"`, the text "(affiliate link)", and `data-aff="<partner>-<page-slug>"` (partners: `apostille-usa`, `fingerprints-apostilles`). Update `/disclosure/` ("Current status") when partners change.

## Reading affiliate click events in GoatCounter
Pages containing a `data-aff` link include a tiny inline script: a click sends a cookieless GoatCounter event with path `aff-<partner>-<page-slug>` (e.g. `aff-apostille-usa-texas`, `aff-fingerprints-apostilles-fbi-background-check-apostille`) and title "Affiliate click: <partner> (<page path>)". No cookies or personal data; if count.js didn't load (ad blocker), nothing is sent.
- Dashboard: https://apostille-atlas.goatcounter.com/ (login in the vault). Events appear in the main "Pages" list alongside page views, marked as events; type `aff-` in the filter box at the top of the dashboard to show only affiliate clicks. Each row = clicks for one partner on one page in the selected date range.
- Clicks per page = the `<page-slug>` part; clicks per partner = sum rows by prefix. Compare with the page's views for a click-through rate.
- Clicks are not sales: confirm referrals/commissions in each partner's own dashboard (Apostille USA partner dashboard, Fingerprints & Apostilles FirstPromoter).
- Test: open a page, click an affiliate link, then look for the `aff-...` row (may take a minute).

## Deploy (needs one free account, chosen by the owner)
- **Cloudflare Pages / Netlify / Vercel**: drag and drop or connect the repo; output folder `dist`, build command `python3 build.py`. `netlify.toml` is included.
- **GitHub Pages**: push to a repo; `.github/workflows/pages.yml` builds and publishes `dist/`.
